# 📊 End-to-End Sales Data Analysis

An interactive **Sales Data Analysis Dashboard** developed using **SQL, Excel, and Power BI** to analyze sales performance, costs, quantities, products, brands, categories, customers, and regional trends.

### 🛠️ Tools Used

* SQL
* Microsoft Excel
* Power BI
* DAX
* Data Visualization

### 📌 Key Analysis

* Total Sales and Total Cost
* Product and Category performance
* Brand-wise sales analysis
* Regional/state-wise sales
* Quantity and transaction analysis
* Sales trends over time
* Interactive filters and slicers

### 🎯 Objective

To transform raw sales data into meaningful business insights through **data cleaning, analysis, visualization, and an interactive Power BI dashboard**.
